This folder contains point sets and code related to the "Other Discrepancy" section of our paper. 
It inlcudes:
1. Code for computing original and smoothed version of periodic, general and extreme L_2 discrepancy.
2. Point sets initialization functions include Fibonacci, Sobol, Halton and random initialization and also Fibonacci lattices, conjectured to be optimal in L_2 periodic discrepancy.
3. Files include examples in paper for each discrepancy value test.
